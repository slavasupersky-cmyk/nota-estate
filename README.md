# NOTA Estate

Сайт nota.estate и рабочие страницы для клиентов и агентов. Статика — открывается в браузере, без сборки и зависимостей.

## Сайт

| Файл | Что это |
|---|---|
| `index.html` | Главная: метод из 17 проверок (тизер), база, пример подборки, калькулятор, подбор и цены, команда, разборы и рейтинги, правила, вопросы, контакт |
| `metod.html` | Метод: паспорт дома (9 проверок) и глубокая проверка (8), красная линия из 5 стоп-факторов, итог |
| `podbor.html` | Подбор: анкета, как работаем, что вы получите, цены |
| `karta.html` | Карта и список 288 домов с фильтрами (класс, ключи, формат) — `<main>` собирает `tools/karta.py` |
| `doma/` | Карточки домов с паспортом — собирает `tools/doma.py`, руками не править |
| `razbory.html`, `razbory/<slug>/` | Разборы: решения (первичка или вторичка, классы новостроек), дома, районы, отказы |
| `razbor-hamovniki.html` | Разбор района — Хамовники |
| `reytingi.html`, `reytingi/<slug>/` | Рейтинги (тёмная тема): школы Москвы, пентхаусы — страницы собирает `tools/reytingi.py` из `data/` |
| `scenarii.html` | Двенадцать сценариев подбора |
| `nota-index.html`, `index-2026-08.html`, `index-2026-09.html` | Старые адреса — переадресация на `reytingi.html`, `razbory/klassy-novostroek/`, `reytingi/shkoly-moskvy/` (пишет сборка) |

`css/nota.css`, `js/nota.js` — общие стили и скрипты (фильтры, анкета, выпадающие списки).
`img/` — кадры сайта, лёгкие JPG. Исходники в `img/_src/` — в репозиторий не попадают.
`favicon.svg` — знак, лежит в корне: папка `icons/` попадает под `Icon?` в .gitignore.

## Сборка

`python3 tools/build.py` — пересобрать после любой правки общих частей:
- `tools/partials/header.html`, `footer.html` — шапка и подвал, раскладываются во все страницы сайта;
- `tools/site.json` — телефон, почта, каналы, офис, реквизиты ИП (подвал и политика);
- `tools/doma.json` — какие дома получают карточку и текст «На заметку:»; цифры и паспорт берутся из `data/doma.csv` и `data/proverki.csv` (выгрузка из `nota-baza`, `tools/baza.py`).
- `tools/reytingi.py` — рейтинги из `data/shkoly.csv`, `data/marshruty.csv`, `data/penthausy.csv`, снимка школ и `data/shkoly-arhitektura.json`.

Результат — обычные статичные HTML-файлы: поисковики и нейросети видят весь текст.

## Чего здесь нет

Рендеры, презентации и исходники материалов в репозиторий не кладём — для них облако.
Ограничения GitHub: файл до 100 МБ, репозиторий желательно до 1 ГБ, а история хранит
все прошлые версии файлов навсегда. `.gitignore` не пустит тяжёлые форматы, даже если
они случайно окажутся в папке.
