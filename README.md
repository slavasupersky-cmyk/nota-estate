## Публикация

Адрес: `https://<аккаунт>.github.io/nota-estate/`

## Чего здесь нет

Рендеры, презентации и исходники материалов в репозиторий не кладём — для них облако.
Ограничения GitHub: файл до 100 МБ, репозиторий желательно до 1 ГБ, а история хранит
все прошлые версии файлов навсегда. `.gitignore` не пустит тяжёлые форматы, даже если
они случайно окажутся в папке.
